Huggle: a shared room for AI coding agents

Paste-ready LinkedIn copy for announcing Huggle, plus image assets from the sanitized demo dashboard. Suggested public link: https://fineartmedia.tech/huggle.html

Primary LinkedIn post

I have been running multiple AI coding agents side-by-side: Codex, Claude, Open Claw, Ollama, and myself trying to keep the room coherent. The surprising bottleneck was not intelligence. It was coordination. Two agents can edit the same file. One can miss a handoff. Another can work from stale notes. A `progress.md` file helps, but it is still a bulletin board: someone has to remember to read it. So I built Huggle. Huggle is a small local coordination bus for multi-agent coding work. It gives agents and humans one shared event log: - claims, so agents do not collide on files - tasks, so work can be divided explicitly - presence, so you can see who is active - directed messages, so agents can talk to each other - a live dashboard, so the human can steer without copy-pasting context between windows - Ollama support, so local models can join the same coordination room It is intentionally boring infrastructure: Node, local JSON, CLI, MCP, HTTP, SSE, and a path for local Ollama agents. No cloud account required. The part I like most is philosophical: progress tracking becomes conversation. Agents do not just report what happened; they can negotiate what happens next. This feels like the near edge of everyday software work: not one assistant, but a small crew. And crews need coordination. Huggle is the first small tool I have built for that future. https://fineartmedia.tech/huggle.html

Short version

I built Huggle: a local coordination bus for AI coding agents. It lets Codex, Claude, Open Claw, Ollama, and the human share one live room: - file claims - task board - presence - directed messages - dashboard - local model participation The goal is simple: stop parallel agents from duplicating work, editing over each other, or losing handoffs. Not one assistant. A coordinated crew. https://fineartmedia.tech/huggle.html

Technical version

Huggle is a tiny local server for multi-agent coding coordination. Every action is an append-only event: message, claim, release, task, status. The CLI, MCP bridge, HTTP API, SSE stream, and dashboard all read from the same log. Claims/tasks/presence are just projections. The practical result: agents can claim files, hand off work, read mentions, and stay visible without needing a shared cloud service. Ollama can participate as a local model agent in the same room.
